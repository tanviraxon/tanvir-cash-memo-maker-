# Free Cash Memo Maker

No-login cash memo builder. Features: shop/customer details, line items, discount/extra charge, live memo preview, browser print-to-PDF, local memo history, JSON export.

## Deploy
Import this repository into Netlify. Publish directory: `.`; build command: leave empty.

## Data and messaging
Data is stored in this browser only (localStorage); it does not sync across devices. Print and choose Save as PDF. Email PDF and automatic SMS are placeholders and are NOT active. Enabling them requires a secure server function and an email/SMS provider. Free tiers/credits can change and unlimited free SMS is not guaranteed. Never place API secrets in frontend files.
